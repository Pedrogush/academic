# Adaptação de Segundo Nível Usando Modelos Fixos com Desligamento do Sinal Persistentemente Excitante

**Authors:** P. Y. Gushiken, A. D. de Araújo  
**Venue:** XXI Congresso Brasileiro de Automática (CBA 2016), Vitória-ES, paper 0420 — published

Final proceedings PDF and LaTeX source in `paper/`, conference slides in `slides/`, and the simulation scripts in `code/`: `L2A_Dif_ModDes_SatAlfa.m` (Simulations 1–2), `…_Pert.m` (Simulation 3, disturbance), `…_Rui.m` (Simulation 4, noise). `code/Parametros de Simulacao/param_sim_CBA.mat` is the Simulation 1 parameter set; `CBA1…CBA10.mat` are later reruns, not the published runs.

`code/` holds 27 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
