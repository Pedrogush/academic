# Sistemas de Controle (EEC1110)

**Graduate coursework**, 2016.1 — PPgEEC/UFRN, Prof. Carlos Eduardo Trabuco Dorea

Team project (Van der Pol system, root locus and frequency-response design) by **Isaac Dantas**, **Luan Garcia** and Pedro. Teammates' e-mails were removed from the LaTeX title block; the compiled PDF that prints them is not included.

`code/` holds 18 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
