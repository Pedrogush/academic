# Information Theoretic Learning

**Graduate coursework**, 2016.2 — PPgEEC/UFRN, Prof. Allan de Medeiros Martins

Course paper "least squares vs. correntropy in indirect adaptive pole-placement control" (SBA format) and slides; `code/` has the parameter sets (`sim_appc.mat`, final `appc_artigo.mat`) and the block-diagram figures. The correntropy estimator code itself was not found.

`code/` holds 8 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
