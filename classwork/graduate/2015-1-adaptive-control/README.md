# Controle Adaptativo (taken during undergrad)

**Graduate coursework**, 2015.1 — PPgEEC/UFRN, Prof. Aldayr Dantas de Araújo

Lists 1–4 in PSIM (MRAC with MIT rule, gradient / least-squares estimation, PE attenuation — the "Bonus" idea that became the TCC); reports for units 2 and 3–4.

`code/` holds 59 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
