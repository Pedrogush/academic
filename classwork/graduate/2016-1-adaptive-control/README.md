# Controle Adaptativo

**Graduate coursework**, 2016.1 — PPgEEC/UFRN, Prof. Aldayr Dantas de Araújo

Unit 1 report; MRAC Trabalho 1 in Simulink; identification and control methods (gradient, least squares, APPC, MRAC, Åström–Hägglund) written with **Isaac Dantas Isidório** (headers: "Alunos: Pedro Gushiken e Isaac Dantas"). `MRACDireto_Gradiente_Deducao_Winnie.slx` is your model built from classmate **Winnie de Lima Torres**' derivation. Some scripts call functions that are missing (`theta_fromf.m`).

`code/` holds 63 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
