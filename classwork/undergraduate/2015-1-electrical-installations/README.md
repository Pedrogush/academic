# Instalações Elétricas

**Undergraduate coursework**, 2015.1 — UFRN

Building installations project with **Frankelene Pinheiro de Souza** and **Lucas Marcelino dos Santos**. The Word memorials list team members' home addresses and are held back.

`code/` holds 1 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
