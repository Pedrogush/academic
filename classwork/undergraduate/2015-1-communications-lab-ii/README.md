# Laboratório de Comunicações II (Labcom)

**Undergraduate coursework**, 2015.1 — UFRN, Prof. Antonio Luiz Campos

Unit 2 project (PWM demodulator) with **José Verismar Júnior**; PSIM stage simulations in `code/`.

`code/` holds 14 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
