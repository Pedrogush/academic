# Comunicações Digitais (DCO0010)

**Undergraduate coursework**, 2015.2 — UFRN, Prof. Marcio Rodrigues

Some eye-diagram scripts in `code/` adapt base code supplied with the assignment (likely from B. P. Lathi's textbook); see each file's notes.

`code/` holds 4 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
