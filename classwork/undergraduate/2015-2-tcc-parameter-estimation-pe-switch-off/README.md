# Trabalho de Conclusão de Curso (TCC): Identificação de Parâmetros através de Sinal PE com Esquema de Desligamento Automático

**Undergraduate coursework**, 2015.2 — UFRN, advisor Prof. Aldayr Dantas de Araújo

Report (PDF + LaTeX) and slides; PSIM and Simulink estimators in `code/` (finals: `1 polo/POParAgRL.slx`, `2 polos/SegOrdem.slx`).

`code/` holds 52 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
