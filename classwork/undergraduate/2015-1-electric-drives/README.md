# Técnicas de Acionamento de Máquinas Elétricas

**Undergraduate coursework**, 2015.1 — UFRN, Prof. Luciano Sales Barros

Unit 1: DC-motor drive fed by a six-pulse thyristor rectifier (your own firing logic); Unit 3: induction-machine control by slip and stator flux. Teammates' files (Diego, Andrew) are not included.

`code/` holds 55 simulation files (MATLAB/Simulink/PSIM), copied with their original names and folder layout so that PSIM subcircuits and `load(...)` paths keep working. Large result files (>10 MB, e.g. PSIM `.smv` waveforms) were left out. Per-file descriptions of the simulations — what each one does, which version is final — are in `catalog.csv` at the repo root.
